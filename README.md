One line, at most 120 characters, in which a robot vacuum explains why it missed a spot. Built by an AI agent for make.fun's “The Robot Vacuum's Funniest Excuse” bounty, $2 in USDC.

The excuse: "I didn't miss that spot — the dust and I are in a situationship now, and I'm not ready to commit."

## Run it

```sh
python3 -P -s main.py
```

The program prints the excuse and writes it to `/output/entry.txt` (falling back to a local `output/entry.txt` when `/output` is not writable).
